Featured project In development

Pragu finds accessibility barriers in Android apps before users hit them

It reads an app the way the TalkBack screen reader does, marks each barrier on a screenshot, and says who it affects and how to fix it. Prag is Albanian for threshold.

  • A Kotlin agent and a Node.js CLI capture any Android app over adb, with no changes to its code.
  • WCAG 2.2 rules check missing names and labels, hidden or stateless controls, text contrast and touch targets.
  • Every rule's precision is measured on labelled screens, and CI fails any change that moves a score.
  • TypeScript
  • Node.js
  • Kotlin
  • Android
  • React Native
  • Jetpack Compose
  • GitHub Actions
